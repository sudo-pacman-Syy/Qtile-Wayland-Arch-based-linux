## 🗲 Command Qtile 
- `super + enter` open terminal
- `super + h + j + k + l` moving by terminal
- `super + '+'` control sound (up)
- `super + '-'` control sound (down)
- `super + control + r` restart qtile
- `super + w` kill focused window
- `super + taq` change layout
- `super + alt` open rofi
- `PRTSC` print screen
